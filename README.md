# PetShop

Proyecto de la asignatura de Lenguajes de Marcas (1º DAW).

Es la página web de una tienda de productos para mascotas, hecha solo con HTML y CSS.

## Qué tiene

- Cabecera con el logo y un menú para ir a cada sección.
- Banner con una promoción.
- Categorías: perros, gatos, aves y peces.
- Productos destacados con su precio y valoración.
- Promociones y ofertas.
- Sección sobre nosotros.
- Formulario de contacto.
- Pie de página con redes sociales.

Los iconos son de Font Awesome.

## Cómo verla

1. Descargar el repositorio.
2. Abrir el archivo index.html en el navegador.

No hace falta instalar nada.

## Carpetas

- index.html: la página principal
- css: estilos de la web
- imagenes: fotos de las categorías y de los productos
